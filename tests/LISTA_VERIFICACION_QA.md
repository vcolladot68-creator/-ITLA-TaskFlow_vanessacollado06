# Lista de verificación de calidad - ITLA TaskFlow

## 1. Autenticación
- [ ] El usuario puede registrarse.
- [ ] El usuario puede iniciar sesión.
- [ ] El usuario puede cerrar sesión.
- [ ] Las páginas privadas requieren autenticación.

## 2. Gestión de tareas
- [ ] Se pueden crear tareas.
- [ ] Se pueden consultar las tareas.
- [ ] Se pueden actualizar las tareas.
- [ ] Se pueden eliminar las tareas.
- [ ] Se validan los campos obligatorios.

## 3. Búsqueda y filtros
- [ ] La búsqueda permite localizar tareas.
- [ ] El filtro por estado funciona.
- [ ] El filtro por prioridad funciona.
- [ ] Se puede limpiar la búsqueda y los filtros.

## 4. Base de datos
- [ ] La conexión con MySQL funciona.
- [ ] Los registros se almacenan correctamente.
- [ ] Las migraciones se pueden aplicar.

## 5. Interfaz
- [ ] Las páginas cargan correctamente.
- [ ] Los formularios muestran mensajes de validación.
- [ ] Los mensajes de confirmación y error son visibles.
