\# Historial de cambios - ITLA TaskFlow



\## Información del proyecto



\- Nombre: ITLA TaskFlow

\- Tipo: Aplicación web de gestión de tareas y proyectos.

\- Tecnologías: Python, Flask, MySQL, HTML, CSS y Bootstrap.

\- Control de versiones: Git y GitHub.

\- Modelo de trabajo: Git Flow.



\## Versión 1.0.0 - Desarrollo inicial



\### Funcionalidades principales

\- Implementación de la estructura inicial de la aplicación.

\- Configuración del entorno de desarrollo con Flask.

\- Integración con la base de datos MySQL.

\- Implementación del sistema de autenticación.

\- Registro e inicio de sesión de usuarios.

\- Gestión de tareas mediante operaciones CRUD.

\- Organización de tareas y proyectos.

\- Incorporación de categorías para clasificar las tareas.



\### Mejoras de interfaz

\- Diseño de páginas utilizando plantillas HTML.

\- Integración de Bootstrap.

\- Organización de las vistas de la aplicación.

\- Mejoras en la navegación entre secciones.



\### Validaciones

\- Validación de información ingresada en formularios.

\- Comprobación de campos requeridos.

\- Manejo de mensajes para informar al usuario sobre las operaciones realizadas.



\### Calidad y documentación

\- Elaboración de documentación del proyecto.

\- Incorporación de un plan de pruebas.

\- Creación de listas de verificación de calidad.

\- Preparación de un formato para reportar incidencias.



\## Control de versiones



El desarrollo se organiza mediante Git Flow:



\- main: contiene las versiones finales del proyecto.

\- developer: contiene el desarrollo de funcionalidades.

\- qa: permite realizar las pruebas de calidad.

\- feature: permite desarrollar funcionalidades o mejoras específicas.

\- hotfix: permite corregir problemas urgentes.



\## Objetivo del historial



Mantener un registro de los cambios realizados en ITLA TaskFlow para facilitar el seguimiento del desarrollo, las revisiones y futuras actualizaciones.
